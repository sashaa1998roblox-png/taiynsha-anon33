ТАЙЫНША АНОНИМНО — NETLIFY + ОБЩАЯ ЛЕНТА
========================================

ЧТО ВНУТРИ
----------
index.html                     Твой сайт на основе загруженного HTML.
netlify/functions/social-data.mjs  Серверная функция API.
netlify.toml                   Настройки Netlify: публикация сайта и функции.
package.json                   Зависимости проекта.

КАК ЭТО РАБОТАЕТ
----------------
Сайт размещается на Netlify. Серверная часть запускается как Netlify Function.
Общие публикации, комментарии, реакции и данные опросов хранятся в Netlify Blobs.
Тебе не нужно держать компьютер включённым.

ВАЖНО ПРО ОГРАНИЧЕНИЯ ЭТОЙ ПЕРВОЙ ВЕРСИИ
----------------------------------------
1. Netlify Functions — это серверная функция по запросу, а не постоянно работающий
   процесс/WebSocket-сервер. Для обычного API сайта этого достаточно.
2. Общая лента (публикации/комментарии/реакции/опросы) синхронизируется через API.
3. Профили и текущий выбранный профиль пока остаются локальными в браузере.
   Поэтому полноценной общей регистрации и безопасного входа ещё нет.
4. Админ-панель сохранена. Она показывается профилю с юзернеймом s3anchezz.
   ВНИМАНИЕ: это только клиентская проверка. Любой технически подготовленный
   посетитель может её обойти. Для настоящей защиты нужна серверная авторизация.
5. Это стартовый MVP. Netlify Blobs — key/value-хранилище, не полноценная
   реляционная база данных. При большом количестве одновременных изменений
   возможны перезаписи. Для большого публичного сообщества позже лучше перейти
   на PostgreSQL/Netlify Database или другой полноценный backend.
6. Публичный API принимает отправку публикаций. Перед широким запуском добавь
   серверную защиту от спама, лимиты, авторизацию и модерацию. Не публикуй личные
   данные пользователей.

САМЫЙ БЫСТРЫЙ СПОСОБ РАЗВЁРТЫВАНИЯ
---------------------------------
Для этого архива нужен GitHub-подключённый деплой: простая загрузка HTML через
Netlify Drop не запускает Netlify Functions. Самый простой вариант без командной
строки — загрузить файлы через сайт GitHub и подключить репозиторий к Netlify.

КАК РАЗВЕРНУТЬ НА NETLIFY
------------------------
Для Netlify Functions одного перетаскивания index.html или ZIP в Drop area
недостаточно. Функции нужно развернуть вместе с проектом через Git или Netlify CLI.
Самый простой путь — GitHub.

ШАГ 1. РАСПАКУЙ АРХИВ
1. Создай на компьютере папку, например TAIYNSHA_ANON_NETLIFY.
2. Распакуй в неё всё содержимое ZIP.
3. Проверь, что index.html и netlify.toml лежат прямо в корне папки,
   а social-data.mjs находится в netlify/functions/.

ШАГ 2. ЗАГРУЗИ В GITHUB
1. Открой https://github.com/ и войди в свой аккаунт.
2. Создай новый репозиторий, например taiynsha-anon.
3. Если репозиторий будет публичным, не добавляй в него пароли, токены
   или другие секреты. В этом проекте секретов в коде быть не должно.
4. Загрузи файлы и папку netlify из распакованного архива в корень репозитория.

ШАГ 3. ПОДКЛЮЧИ РЕПОЗИТОРИЙ К СВОЕМУ ПРОЕКТУ NETLIFY
1. Открой https://app.netlify.com/teams/sashaa1998roblox/projects
2. Открой нужный проект сайта.
3. Найди Project configuration / Site configuration.
4. Открой Build & deploy → Continuous deployment.
5. Выбери Link repository / Connect to Git provider.
6. Подключи GitHub и выбери репозиторий taiynsha-anon.
7. Build command оставь пустой.
8. Publish directory укажи точкой: .
9. Functions directory: netlify/functions (если поле показывается; netlify.toml уже задаёт его).
10. Сохрани настройки и запусти Deploy.

Если в интерфейсе нет кнопки Link repository, можно создать новый сайт через
Add new project → Import an existing project → GitHub и выбрать этот репозиторий.
В таком случае Netlify создаст новый сайт с отдельной ссылкой.

ШАГ 4. ПРОВЕРЬ API
После успешного Deploy открой адрес своего сайта и добавь в конец:
/.netlify/functions/social-data
Например:
https://ТВОЙ-САЙТ.netlify.app/.netlify/functions/social-data
Должен появиться JSON примерно такого вида:
{"posts":[]}
Если видишь ошибку, открой Deploys → последний Deploy → Function logs.

ШАГ 5. ПРОВЕРЬ ОБЩУЮ ЛЕНТУ
1. Открой сайт в обычном окне браузера.
2. Создай тестовую публикацию.
3. Открой сайт в другом браузере или на другом устройстве.
4. Проверь, появилась ли публикация там.

ОБНОВЛЕНИЕ САЙТА
----------------
После изменений загружай новые файлы в тот же GitHub-репозиторий.
Netlify автоматически соберёт и опубликует новую версию.
